About DinSide

Tối ưu hóa luồng làm việc giữa Web và Trí tuệ nhân tạo

Thông thường khi dùng ChatGPT hay Claude, bạn phải liên tục bôi đen, copy và chuyển tab để dán vào khung chat. DinSide loại bỏ hoàn toàn rào cản này bằng cách mang chatbot vào ngay bên cạnh trang bạn đang đọc.

  • ✓
    Tự động đọc cấu trúc trang và vùng nhìn (Viewport)

    Chỉ gửi những nội dung bạn đang quan tâm thay vì gửi tràn lan gây nghẽn context.

  • ✓
    Ghim ngữ cảnh (Pin Context) và gom nhiều Tab

    Giữ lại tài liệu tham khảo cho nhiều câu hỏi liên tiếp mà không cần chọn lại.

  • ✓
    Bảo mật tuyệt đối — 100% mã nguồn mở

    Mã nguồn công khai trên GitHub, chạy cục bộ dưới dạng Manifest V3 tiện lợi.

Quick Setup

Hướng dẫn cài đặt trong 1 phút

Tương thích Chrome, Edge, Brave, Cốc Cốc
DinSide-0.6.9.zip (Bản mới nhất) Định dạng ZIP · Dung lượng ~2.4 MB · Không cần npm build
Tải bản ZIP về máy
1
Giải nén file

Giải nén file ZIP vừa tải về vào một thư mục cố định trên máy tính của bạn.

2
Mở trang quản lý Extension

Nhập chrome://extensions vào thanh địa chỉ trình duyệt rồi nhấn Enter.

3
Bật Developer Mode & Load Unpacked

Bật công tắc Developer mode ở góc phải, sau đó bấm Load unpacked ở góc trái và chọn thư mục vừa giải nén.

Clone trực tiếp kho mã nguồn từ GitHub để dễ dàng nhận các bản cập nhật mới qua git pull:

Terminal / Bash / PowerShell 
git clone https://github.com/thanhdiner/DinSide.git
cd DinSide

Sau khi clone, vào chrome://extensions, bật Developer mode và bấm Load unpacked trỏ vào thư mục vừa clone. DinSide không bắt buộc npm install để chạy.
